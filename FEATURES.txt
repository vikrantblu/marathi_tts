  Phase A segment library + Phase B Piper VITS fine-tuning. Custom voice engine

  Adaptive silence detection (auto-retries with progressively sensitive thresholds).
- FEAT-51 ✅ Real-time prosody preview — analyze_prosody() bridge returns ProsodyEngine

  stream chunk in-place; progress indicator on regenerating segment.
- FEAT-53 ✅ Dual-engine A/B comparison — compare_engines() in both mobile + desktop
  bridges. Runs text through gTTS, Edge-TTS, and custom voice, returns all results
  for side-by-side quality comparison.
- FEAT-VQ ✅ Verse voice quality — new _generate_edge_verse_prosody() in both mobile +
  desktop bridges. Uses ProsodyEngine metre-aware segmentation (pauses at ।/॥, pitch
  contour, per-metre tts_rate) to generate per-segment edge-tts neural audio with
  calibrated verse pauses. Previously verse text bypassed prosody pipeline and fell to
  robotic gTTS slow=True. Now: edge-tts verse prosody → single edge-tts → gTTS fallback.

### Voice Quality

- FEAT-73 ✅ G2P anusvara assimilation: _process_anusvara() implemented with

- FEAT-74 ✅ Multi-speaker voice selection: _EDGE_VOICE_MAP supports Aarohi (female) and

- FEAT-76 ✅ Export to MP3 with metadata: exportAudioWithMetadata() saves to Music/MarathiTTS

- FEAT-77 ✅ Widget for quick TTS: Android home screen widget (4×1) with "Speak Clipboard"

### Code Quality

- FEAT-80 ✅ Per-verse metre detection: detect_line() + detect_per_line() in MetreEngine;

### Dynamic UI (FEAT-81/82)
- FEAT-81 ✅ Mini-player bar: activity-scoped PlaybackViewModel owns AudioPlayerService so

- FEAT-82 ✅ Back-nav dialog: OnBackPressedCallback shows MaterialAlertDialog when audio is

### BookReader Scanner Overhaul (FEAT-83)
- FEAT-83 ✅ OSS-inspired pure-Kotlin book scanner. NO new dependencies, NO cloud APIs.
  - Live edge detection: per-frame quad detection on CameraX ImageAnalysis
    (LiveEdgeDetector, 640×480 thumbnails, STRATEGY_KEEP_ONLY_LATEST).
  - Live HUD: LiveQuadOverlayView draws quad outline + corner dots + countdown ring +
    status pill (IDLE/ADJUSTING/STABLE/WARNING colour states).
  - Frame quality gating: FrameQualityAnalyzer rejects blurry frames (Laplacian
    variance < 60) and glare-saturated frames (>3% pixels at luminance 245+).
  - Auto-capture: BulkScanController state machine (IDLE → ADJUSTING → STABLE_HOLDING
    → FIRING → POST_CAPTURE_HOLD → AWAITING_PAGE_CHG) with 800 ms stable hold +
    1200 ms post-capture lockout. Toggle AUTO ↔ MANUAL via shutter-panel button.
  - Bulk-scan mode: BULK toggle keeps the camera open across many pages, accumulates
    captured page JPEGs, shows a page-count chip + Done button. Page-change detection
    uses centre-shift fraction or brightness delta after each capture.
  - Sobel edge refinement: PageEdgeDetector.refineWithSobel() snaps each detected
    edge to the strongest gradient ridge within ±5% of the projection peak (3×3
    Gx/Gy kernels). Adds +0.10 confidence bonus when snap succeeds.
  - Auto-split spreads: when isSpreadMode and the deskewed bitmap is wider than
    tall, BookCameraActivity splits at the midpoint into separate L + R JPEGs.
  - Multi-page return: BookCameraActivity now sets EXTRA_IMAGE_PATHS (ArrayList) in
    addition to the legacy single EXTRA_IMAGE_PATH; BookReaderViewModel gains
    processMultiplePages() that walks pages sequentially with status updates.
  - PDF export: BookPdfBuilder writes captured pages to A4 PDF (24 pt margins,
    fit-aspect-ratio centring) into Downloads/MarathiTTS via MediaStore (Q+) or
    legacy Environment path. Offered via Snackbar action after multi-page capture.
