## Planned

### High Priority
- FEAT-1 Wire ProsodyEngine.segment_text() into mobile/desktop bridges for natural
  clause/sentence pauses in prose (currently sends entire text as one chunk)
- FEAT-2 Desktop streaming/chunking for long text (>250 chars) — mobile & web have it
- FEAT-3 Grammar engine as hard dependency on desktop/mobile (currently silently skipped
  if import fails, but it's pure Python with no heavy deps)
- FEAT-8 Edge-TTS SSML generation: use <break>, <prosody rate/pitch>, <emphasis> tags
  instead of pydub post-processing for native neural-quality prosody
- FEAT-23 Move English-to-Devanagari transliteration to shared tts/utils/text/ module
  (currently mobile-only)

### Medium Priority
- FEAT-4 MetreEngine: add gaṇa (metrical foot) pattern matching for distinguishing metres
  with same syllable count (Indravajra vs Trishtubh, both 11 syllables)
- FEAT-5 SandhiEngine: add visarga + voiced consonant → r rule (पुनः+दर्शनम्→पुनर्दर्शनम्)
- FEAT-6 Implement yati (caesura) pauses within pādas based on detected metre
- FEAT-7 Ovi rhythmic pulse: lines 1-3 flowing (rate=0.82), line 4 cadence slowdown
  (rate=0.75, longer pause)
- FEAT-9 Emotion → verse prosody mapping (devotional→slower+deeper, peaceful→longer pauses)
- FEAT-11 Implement pitch contour from MetreDefinition (wave/falling/rising/level)
- FEAT-10 Expand schwa deletion lexicon to 200+ entries with suffix-based patterns
- FEAT-20 Hash-based audio caching (SHA256 of text+engine+params → cached audio path)

### Lower Priority
- FEAT-12 Add missing Sanskrit metres: Upajati, Indravajra, Vamshastha, Rathoddhatā,
  Sragdharā (21 syllables)
- FEAT-13 Abhanga refrain (धृवपद) detection with emphasis + pitch boost
- FEAT-14 Pre-recorded stotra audio on mobile (desktop already has fingerprint matching)
- FEAT-15 Chandrabindu lighter nasalization via SSML volume wrapper for edge-tts
- FEAT-16 Dead code removal: prosody_engine.py lines 251-260 (unreachable after return)
- FEAT-32 Test coverage: add tests for TextNormalizer, GrammarEngine, number_to_words,
  bridge preprocessing
