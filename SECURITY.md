# Security Policy

## Supported Versions

We provide security updates for the latest major and minor release lines:

| Version | Supported          |
| ------- | ------------------ |
| 4.1.x   | :white_check_mark: |
| 4.0.x   | :x:                |
| < 4.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in Marathi TTS, please report it responsibly:

1. **Do not** file a public GitHub issue.
2. Use **GitHub Private Vulnerability Reporting** via the [Security tab](https://github.com/vikrantblu/marathi_tts/security/advisories/new).
3. Provide:
   - A description of the issue and potential impact
   - Clear reproduction steps or Proof of Concept (PoC)
   - Impacted platform(s): Web, Desktop, and/or Mobile

We will acknowledge receipt within 48 hours and work on a fix in a private branch before publishing a release and security advisory.
